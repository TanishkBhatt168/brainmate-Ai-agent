3. DUPLICATE ID & VERSIONING DECISION
------------------------------------------------------------------------------
• Finding on arXiv IDs:
  Every record in the raw dataset possesses a unique 'id' string (e.g., cs-9308101v1,
  cs-9308101v2). However, some papers share a base identifier representing different
  versions (v1, v2) submitted to arXiv over time, or cross-listed categories.

• Methodological Decision:
  We do NOT discard papers merely because their IDs share a base identifier or version
  tag. If authors revised an abstract or submitted distinct versions, they remain valid
  scientific publications. However, if the exact normalized (Title, Summary) text is
  identical, only the first occurrence is kept, removing duplicate redundancy (38 records).

4. WHITESPACE NORMALIZATION
------------------------------------------------------------------------------
• Text Normalization Applied:
  - Stripped leading and trailing whitespace from titles and summaries.
  - Collapsed internal newline characters (\n), carriage returns (\r), and tabs (\t)
    into single clean spaces.
  - Replaced multiple consecutive whitespace characters with a single space.
  -> Important: No scientific terminology, domain abbreviations, or vocabulary words
     were removed. Only formatting artifacts were normalized.
